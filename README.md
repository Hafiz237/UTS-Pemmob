## Informasi Aplikasi
- nama Aplikasi : Kuis Kita
- Deskripsi Aplikasi : Kuis kita adalah aplikasi kuis pilihan berganda yang menggunakan tema ilmu komputer, memiliki pertanyaan seputar materi ilmu komputer
- Fitur-fitur Yang Tersedia:
  - fitur ganti tema(light dan dark).
  - isi nama sebelum mulai kuis.
  - pilihan ganda yang menunjukkan pilihan benar dan salah dan penjelasan setelah dipilih.
  - dapat kembali ke start page di tengah kuis.
  - tampilan hasil pilihan berganda dengan role yang sesuai dengan tingkatan nilai.
